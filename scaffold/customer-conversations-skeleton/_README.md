# Customer Conversations

(Skeleton — copy this folder into a new Coach House project when starting to collect evidence.)

This folder houses conversation notes, the protocol, and the template. The full guide for *when conversation is the right tool vs. when something lighter is* lives in [the studio-level practice repo](https://github.com/coach-house/coach-house-hcd/blob/main/customer-conversations/_README.md).

---

## Quick start

1. When a conversation happens, copy [`TEMPLATE.md`](./TEMPLATE.md) to `sessions/YYYY-MM-DD-firstname.md`.
2. Fill in every section *the same day*. End with the one-line commit.
3. Reference the session note in the PR that ships the resulting work.

---

## What lives here

- `_README.md` — this file.
- `PROTOCOL.md` — how to run a conversation when one is happening.
- `TEMPLATE.md` — per-session note template.
- `sessions/` — actual conversation notes, one file per conversation.
- `personas/` — optional; create if the project has a varied enough user base that synthesized profiles help.

---

## The rules that survive across projects

1. **Write it down the same day.** Future-you will not remember.
2. **End every conversation with one commit.** "Based on this conversation, we will / will not do X."
3. **Cite the evidence in the PR.** Use the [scaffold PR template](../.github/pull_request_template.md).
4. **Track buyer vs. worker.** Same person sometimes, different person often.
5. **Pay for time.** Coffee cards or product credit. We don't extract free labor.

For the rest, see [the studio-level guide](https://github.com/coach-house/coach-house-hcd/blob/main/customer-conversations/_README.md).
