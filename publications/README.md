## How publications enter this index

When a Coach House publication ships:

1. The piece is published in its proper venue (white paper in the originating project repo or the practice repo's `publications/` if applicable; newsletter on the chosen platform; talk slides + recording on the studio site).
2. A row is added to the appropriate table above with the title, year, and pointer.
3. The piece is referenced from the next portfolio audit, since publications are part of the practice and should be audited like features.
